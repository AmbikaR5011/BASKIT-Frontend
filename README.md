# 🎨 BASKIT Frontend

This is the frontend of the BASKIT grocery delivery application built using Next.js. It provides a user-friendly interface for browsing products, managing the cart, and placing orders.

---

## 🚀 Tech Stack
- Next.js
- JavaScript
- HTML
- CSS

---

## 🔌 Features
- Browse products
- Add/remove items from cart
- Place orders
- Backend API integration

---

## 🛠️ Setup

1. Clone the repository  
   https://github.com/AmbikaR5011/BASKIT-Frontend  

2. Install dependencies  
   `npm install`

3. Run the application  
   `npm run dev`

4. Open in browser  
   http://localhost:3000
