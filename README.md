# 🎨 BASKIT Frontend – Grocery Delivery Web Application

This is the frontend of the BASKIT grocery delivery system, built using Next.js. It provides an interactive user interface for browsing products, managing cart items, and placing orders.

---

## 🚀 Features

- 🛍️ Browse grocery products  
- 🛒 Add and remove items from cart  
- 📦 Place orders  
- 🔗 Integrated with backend APIs  
- ⚡ Fast and responsive UI using Next.js  

---

## 🧱 Tech Stack

- Next.js  
- JavaScript  
- HTML  
- CSS
